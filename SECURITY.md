# Security policy

## Supported versions

Until the first stable release, security fixes target the latest commit on
`main`.

## Reporting a vulnerability

Use GitHub private vulnerability reporting when available. Otherwise email
`amine.manai@esprit.tn` with reproduction details. Do not open a public issue for
a vulnerability that could expose footage, location data, credentials or enable
arbitrary code execution.

Never send private footage or GPS traces unless a maintainer explicitly requests
a minimal, consented and redacted sample.
